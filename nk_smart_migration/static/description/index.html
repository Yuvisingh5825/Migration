Orders Data Migration

Move sales and purchase orders, with their deliveries, invoices and bills, from another Odoo database into this one. The links between the documents are kept.

How it works

  1. Connect: enter the URL, database, login and API key of the source Odoo, then click Test Connection.
  2. Choose: pick the date range and which records to copy: sales orders, purchase orders, deliveries / receipts, invoices / bills.
  3. Preview and Validate: a dry run lists problems before anything is created.
  4. Start Migration: records are created in batches. Click again to continue. Records already migrated are skipped.
  5. Review the Migration Report: every record is marked Success, Skipped or Failed with a message.

Features

  • Sales orders and purchase orders with their lines and taxes
  • Deliveries and receipts linked to the orders
  • Customer invoices and vendor bills linked to the orders, posted when they were posted in the source
  • Products matched by internal reference (or by name), with a safe option for duplicate names
  • Safe to run again: already migrated records are not duplicated
  • Batch size setting to keep each run short
  • Only system administrators can see and use the module

Good to know

  • Payments are not migrated. If a source invoice was paid, the report tells you to create the payment manually.
  • Products and contacts are matched in this database, so they should already exist here.
  • The module connects to the source Odoo you enter, over its standard external API, and only reads data from it. No data is sent anywhere else.
  • The API key you enter is saved on the migration record. Delete the record when you are done.
  • Always try it on a test copy of your database first.

Requirements

Odoo 19.0 with Sales, Purchase, Inventory and Accounting installed. The source Odoo must allow external API access and you need an API key for a user there.
